# Smart Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. It supports basic arithmetic operations, keyboard input, decimal numbers, and a dynamically adjusted result display.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Percentage operator
- Decimal number handling
- Clear All and Delete functionality
- Keyboard support for numbers and operators
- Enter key to calculate results
- Backspace to delete the last character
- Escape key to clear the calculator
- Dynamic font sizing for long expressions and results
- Maximum input length limit
- Automatic handling of leading zeros
- Improved input behavior after calculating a result

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation and event handling)

## How to Use

1. Enter numbers using the calculator buttons or keyboard.
2. Select an arithmetic operator.
3. Press `=` or `Enter` to calculate the result.
4. Use `DEL` or `Backspace` to remove the last character.
5. Use `AC` or `Escape` to clear the calculator.
6. Use the decimal button to enter decimal numbers.
